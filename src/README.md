# LZ Assessor - Source Code

This directory contains the source code for the LZ Assessor Azure Function application.

## Quick Start

1. Navigate to the function app directory:
   ```bash
   cd LzAssessor.NewVersion
   ```

2. Install dependencies:
   ```bash
   dotnet restore
   ```

3. Run locally:
   ```bash
   func start
   ```

For complete documentation, setup instructions, and architecture details, see the [main README](../README.md) in the repository root.
